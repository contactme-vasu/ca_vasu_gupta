# CONTEXT.md

Single-context glossary for this repo (CA Vasu Gupta website).

## Brand palette (authoritative)

Treat these values as the source of truth for website color:

- CA Blue: `#145886` (CMYK C93 M61 Y24 K9) — primary brand, headers, text accents
- Tricolor Orange: `#F37920` (CMYK C0 M62 Y91 K0) — accent, eyebrow labels, dividers, CTA highlights
- Tricolor Green: `#55B848` (CMYK C67 M0 Y88 K0) — accent, profile panel top border

Use HEX on web. Use CMYK only for print.
